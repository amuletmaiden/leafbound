# LEAFBOUND

A living tarot for two cards.

Each rite is an ordered pair. The first opens a goddess; the second gives her a world. The colors move, gather, change, and hold.

**Play:** https://amuletmaiden.github.io/leafbound/

The game is a self-contained static site. Open `index.html` or serve this directory.

The deck paintings were generated for this project and are stored in `assets/sacred-deck.png`.
